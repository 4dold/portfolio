# Deema Mujally — Cybersecurity Journey Portfolio

## Quick edits

### 1) Your CV
Put your PDF here and name it exactly:
`assets/Deema-Mujally-CV.pdf`

The "View CV" and "Download CV" buttons will then open it.

### 2) Email, phone, and LinkedIn
Open `script.js` and edit only these three lines:

```js
const LINKS = {
  linkedin: "YOUR LINKEDIN URL",
  email: "YOUR EMAIL",
  phone: "YOUR PHONE NUMBER"
};
```

Example:
- LinkedIn: `https://www.linkedin.com/in/yourname`
- Email: `name@example.com`
- Phone: `+9665XXXXXXXX`

### 3) Portfolio text
Open `index.html` in a code editor such as VS Code. The visible text is organized into:
- Hero
- Journey timeline
- Projects
- Certifications
- Skills

### 4) Design
Open `style.css` to change colors, spacing, fonts, and layout.

## Publish on GitHub Pages
Create a repository named:
`YOUR-GITHUB-USERNAME.github.io`

Upload the contents of this folder to the repository, then enable GitHub Pages in the repository settings.
